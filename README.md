A fast, dependency-free drop-in CSV reader that answers exactly as csv-reader 1.0.0 does on every input — broken rows included, with the same columns, rows and errors — and is ranked purely on CPU time.

## Run it

```sh
node main.ts
```

Set MAKEFUN_INPUT_DIR and MAKEFUN_OUTPUT_DIR to choose where cases.json is read from and answers.json is written (defaults: /input and /output).
